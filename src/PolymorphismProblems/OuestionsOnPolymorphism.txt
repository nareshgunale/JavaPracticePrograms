Q.Why method overriding is called late binding or dynamic binding?
Ans: Because the method call is resolued takes place at Runtime(It depends on Object Type not on reference Type)

Q. How do compiler differentiate overloaded methods from duplicate methods?
Ans: If the Method Signature is Same in same class then it is considered as duplicate method.
     If the two methods in the same class have different method Signature then it is considered as Overloading method otherwise it is considered as duplicate methods.

Q.Can you list out the differences between method overloading and method overriding?

Ans:        Overloading                                                Overriding
Same Method name but different Parameter List                     Same Method name and Parameter list
Compile time/Early binding/Static Polymorphism                    Runtime time/Late binding/Dynamic Polymorphism
Can have any Access Modifier                                      Child class method should not be More Restrictive than Parent Class(Less Restrictive)
Return Type does not have any restriction                         Return should be same (Primitive) and Covarient for refernce type(Object)
